### Implications of using cloud technologies to organisations:

| -                              | Implications                                                                                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Disaster recovery policies<br> | If policies aren’t aligned, downtime could be longer, data could be lost, or recovery may cost more than expected.<br>                                                          |
| Security of data<br>           | Poor security controls or unclear data storage locations could result in breaches, fines, or reputational damage.<br>                                                           |
| Compatibility<br>              | If compatibility isn’t considered, organisations may face high costs in re-training, migrating systems, or adapting processes.                                                  |
| Maintenance<br>                | Saves time and resources, but organisations lose some direct control and must trust the provider.<br>                                                                           |
| Fast/Efficient service<br>     | Cloud enables rapid scalability and flexibility, but it might encourage organisations to adopt solutions without fully assessing long-term costs or integration challenges.<br> |
| Performance                    | Poor performance can frustrate staff, reduce productivity, and limit adoption of cloud systems. Organisations must balance local and cloud resources.<br>                       |
