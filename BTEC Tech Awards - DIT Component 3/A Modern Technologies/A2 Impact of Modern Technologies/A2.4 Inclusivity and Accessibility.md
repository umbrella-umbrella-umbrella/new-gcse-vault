# How modern technologies aid Inclusivity and Accessibility
### What is Inclusivity and Accessibility?
- **Inclusivity** means designing and creating things that consider and welcome everyone, regardless of their background, abilities, or circumstances. 
	- *Examples:*
		- A video uses subtitles and sign language so both hearing and deaf audiences can understand.
		- A classroom uses different teaching methods to support students with different learning styles.
- **Accessibility** means making something usable by as many people as possible, especially those with disabilities.
	-  *Examples:*
		- A website includes alt text for images so that screen readers can describe them for visually impaired users.
		- A building has ramps and lifts so wheelchair users can enter and move around easily.

### How modern technologies aid inclusivity and accessibility
- #### Interface design
	- **Layout and Structure**
		- Consistent navigation
		- Responsive design
		- Keyboard accessibility
		- Logical hierarchy
	- **Font and text choices**
		- Readable and scalable text
		- Adequate spacing
		- Contrast and background.
	- **Colour and visual design**
		- High Contrast
		- Colour-blind friendly palettes
		- Avoiding quick, flashy animations
		- Dark and light modes
		
- #### Accessibility features
	- **Screen reader support**
		- Reads aloud everything on screen
	- **Alt text**
		- Describes images for non-visual access
	- **Text-to-speech**
		- Allows users change text size or font
	- **Adjustable typeface**
		- Converts written text to spoken words
		
- #### Flexibility of work hours and locations
	- *Seen in [[A2.1 Changes to Modern Teams|Modern Teams]]*
	- **Remote communication tools**
		- Allow real-time meetings, messaging, and collaboration from anywhere in the world.
	- **Mobile devices and internet** 
		- Smartphones, tablets, and laptops connected to Wi-Fi or mobile data let people work on the go.
	- **Project management software**
		- Allow tasks to be assigned, tracked, and completed collaboratively online.
	- **Cloud computing and file sharing**
		- Store files online and make them accessible on any device with an internet connection.
